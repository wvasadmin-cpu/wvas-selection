# WVAS Exhibitor Selection

Remote committee judging of new exhibitor applicants for the Welland Valley Art
Society.

1. Applications arrive in Airtable.
2. The Membership Secretary picks a round, previews and tidies it, and publishes.
3. One link goes to the committee, who pick their name, say whether they're
   attending the meeting, and otherwise vote Yes or No on each artwork with
   feedback.
4. A private dashboard shows responses and tallies, with a printable A4 summary.

## Development

```bash
npm install
cp .env.example .env.local   # fill in values
npm run dev
npm test
```
